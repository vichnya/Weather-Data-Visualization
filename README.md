# Weather Data Visualization

Учебный проект по получению и визуализации данных о погоде с использованием API OpenWeatherMap.

## Что реализовано

* получение прогноза погоды через REST API;
* получение прогноза на 5 дней с интервалом 3 часа;
* обработка данных о температуре;
* визуализация изменения температуры;
* расчёт средней прогнозируемой температуры для каждого дня;
* построение графика средних дневных температур.

## Визуализация

Программа строит два графика в одном окне:

1. изменение температуры в течение пяти дней;
2. средняя прогнозируемая температура по каждому дню.

## Настройка

Для работы программы необходим API-ключ OpenWeatherMap.

Создайте файл `.env` на основе `.env.example` и укажите в нём свой API-ключ:

```env
OPENWEATHER_API_KEY=your_api_key_here
```

Файл `.env` добавлен в `.gitignore` и не должен загружаться в репозиторий.

## Запуск

Установить зависимости:

```bash
pip install -r requirements.txt
```

Создать файл `.env` и добавить API-ключ.

Запустить программу:

```bash
python main.py
```

Программа получает прогноз погоды через OpenWeatherMap API, обрабатывает данные о температуре, рассчитывает средние значения по дням и отображает результаты в виде двух графиков.
