# Weather Data Visualization

Учебный проект по получению и визуализации данных о погоде с использованием API OpenWeatherMap.

## Что реализовано

* получение исторических данных о погоде через API;
* обработка почасовых температур;
* получение данных за 5 последних дней;
* визуализация изменения температуры;
* расчёт средней температуры для каждого дня;
* построение графика средних дневных температур.

## Визуализация

Программа строит два графика:

1. изменение температуры по часам за 5 дней;
2. средняя температура по каждому из пяти дней.

## Технологии

* Python
* OpenWeatherMap API
* Requests
* Pandas
* NumPy
* Matplotlib
* python-dotenv

## Настройка

Для работы программы необходим API-ключ OpenWeatherMap.

Создайте файл `.env` на основе `.env.example` и укажите в нём свой API-ключ:

```env
OPENWEATHER_API_KEY=your_api_key_here
```

Файл `.env` не должен загружаться в репозиторий.

## Запуск

Установить зависимости:

```bash
pip install -r requirements.txt
```

Запустить программу:

```bash
python main.py
```

Программа получает погодные данные через API, рассчитывает среднюю температуру за каждый день и отображает результаты в виде графиков.
